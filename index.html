Ouvir

Seus livros, lidos em voz natural.

Primeiro acesso: cole uma chave do GitHub para o app acessar seus livros.

  1. Abra github.com/settings/personal-access-tokens/new
  2. Nome: ouvir · Validade: No expiration (ou 1 ano)
  3. Repository access: Only select repositories → audiolivros-dados
  4. Permissions → Repository: Contents: Read and write e Actions: Read-only
  5. Gerar e copiar a chave (começa com github_pat_)

A chave fica salva só neste aparelho.
